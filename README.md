AI Resume Builder

AI Resume Builder is a modern web application designed to help users create professional, ATS-friendly resumes quickly and efficiently using artificial intelligence. The platform allows users to enter their personal details, education, work experience, skills, and projects, while the AI automatically generates optimized resume content and professional summaries.

The application provides real-time resume previews, customizable templates, and PDF download functionality, making resume creation simple and user-friendly. Built with React.js for the frontend and Django for the backend, the project delivers a fast, responsive, and scalable experience for users across desktop and mobile devices.
